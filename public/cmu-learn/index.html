Lecture 1: What Are Agents? And How Do They Work?

요약

첫 강의는 답변을 생성하는 언어 모델과 실제 환경에 조치를 취하는 에이전트를 구분한다. 모델이 도구 사용을 제안하면 실행을 관리하는 프로그램이 입력을 확인하고 결과를 돌려준다. 모델이 그 결과를 바탕으로 다음 행동을 고르는 반복이 에이전트의 기본 구조다. 강의는 신뢰성을 높이는 두 방법으로 모델 자체를 훈련하는 것과 실행 환경에 검증·메모리·안전 규칙을 설계하는 것을 비교한다.

핵심 포인트
  • 도구 호출은 모델이 생성한 요청이고, 실제 실행과 입력 검증은 모델 바깥에서 이루어진다.
  • 도구를 한 번 호출하는 기능과, 결과를 보고 작업을 이어가는 반복 구조를 구분한다.
  • 정확한 도구 사용뿐 아니라 긴 작업의 맥락 유지, 환경 이해와 안전도 설계해야 한다.

Lecture 2: Overview of Machine Learning Systems

같은 학기·회차 강의진 공개 슬라이드 기반. 편집 영상의 직접 시청이나 시간 확인은 하지 않았습니다.

요약

사용자가 적은 모델 정의가 실제 CPU와 GPU에서 실행되기까지 어떤 층을 거치는지 살펴본다. 자동 미분은 역방향 계산을 만들고, 그래프 최적화는 여러 연산의 관계를 보고 불필요한 일을 줄인다. 이후 병렬화, 커널 생성, 메모리 최적화가 각각 실행 비용의 다른 부분을 다룬다.

핵심 포인트
  • 자동 미분은 사용자가 역방향 연산을 모두 손으로 적지 않아도 되도록 계산 구조를 만든다.
  • 합성곱과 배치 정규화를 합치는 예시는 여러 연산을 함께 볼 때 생기는 최적화 기회를 보여준다.
  • 그래프를 바꾸는 일과 계산을 여러 장치에 나누거나 메모리를 아끼는 일은 서로 다른 층의 결정이다.

Lecture 3: Deep Learning and Programming Abstraction

같은 학기·회차 강의진 공개 슬라이드 기반. 편집 영상의 직접 시청이나 시간 확인은 하지 않았습니다.

요약

딥러닝을 여러 층의 함수를 결합한 모델로 바라보고, 모델 구조·손실 함수·최적화 방법의 역할을 나눈다. 이어서 여러 종류의 신경망이 공통으로 쓰는 다차원 배열과 연산을 프로그래밍에서 어떻게 표현하는지 다룬다. 모델이 원하는 계산과 시스템이 실제로 실행하는 구현을 구분하는 것이 핵심이다.

핵심 포인트
  • 모델, 손실 함수, 최적화 방법은 학습에서 서로 다른 역할을 맡는다.
  • 딥러닝은 연결된 층의 매개변수를 함께 학습하는 점이 중요하다.
  • 모델별 차이를 살피되, 텐서와 연산이라는 공통 표현이 왜 유용한지 생각해 본다.
