실무 추천

AI 에이전트 → 운영 → 성능

도구를 쓰는 루프부터 평가와 운영까지. 마지막엔 서빙 병목을 직접 재봅니다.

  1. 11-768 AI 에이전트
  2. 17-645 프로덕션 머신러닝
  3. 15-442 머신러닝 시스템

남길 결과물 동일한 평가 세트의 성공률·p95 지연과 실패 원인을 한 장에 비교하세요.

백엔드·테크 리드

설계 → 아키텍처 → 품질

코드의 책임 분리에서 팀의 설계 결정, 품질 기준으로 시야를 넓힙니다.

  1. 17-214 소프트웨어 구축 원리
  2. 17-635 소프트웨어 아키텍처
  3. 17-643 소프트웨어 품질 관리

남길 결과물 기존 프로젝트를 골라 아키텍처 결정 기록과 릴리스 점검표를 작성하세요.

기초부터

컴퓨팅 → 확률 → 머신러닝

Python과 문제 해결에서 시작해 확률과 모델 평가를 연결합니다. 확률·ML 과목은 1월 공개 예정입니다.

  1. 15-110 컴퓨팅 원리
  2. 15-259 확률과 컴퓨팅 예정
  3. 07-280 AI와 머신러닝 I 예정
  4. 10-605 대규모 데이터 머신러닝

남길 결과물 작은 정형 데이터로 기준 모델을 만들고 검증 결과를 재현하세요.
